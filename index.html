Connect Speakora to Supabase

This file needs your own Supabase project before it can run. It only takes two steps:

  1. Create a free project at supabase.com and run schema.sql in the SQL Editor.
  2. Open index.html in a text editor and paste your Project URL and anon public key (Project Settings → API) into the CONFIG block near the bottom of the file, then reload this page.
